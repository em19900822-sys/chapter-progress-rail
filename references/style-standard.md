# 样式标准（星姐风格 / 预设 xingjie）

参考图：`assets/reference/xingjie.jpg`（星姐抖音完整截图）、`assets/reference/rail_zoom.png`（导航条特写）、`assets/reference/compare_ref_old_new.png`（2026-10-27 的参考/旧版/新版对比）。

## 行家拆解：好在哪 5 条

1. **栏少字少**：3 栏，每栏 3–4 字，格内留白多，一眼扫完。栏越多、字越长，字号就越被压。
2. **字粗**：橙金粗体（Black 字重）+ 深棕粗描边 + 投影；深色、浅色衣服背景上都清楚。细字薄描边在手机上会糊。
3. **填充反差大**：已讲 = 较实的奶油浅黄；未讲 = 更透明的浅灰。半透明金黄压在深色衣服上，“填了”和“没填”几乎看不出差别（我们旧版的问题）。
4. **格子感**：粗橙竖条带深色边做分隔，最左、最右也有端条；等宽格。细分隔线撑不起“格子”。
5. **位置**：通栏，紧贴字幕正下方，在抖音底部标题/话题区上方。眼睛不用来回找；放太低（画面约 80% 处）会被抖音文案盖住。

## 她的方法 & 怎么证明做对了

- 方法：按「问题 → 原因 → 方法」（如 判断类型 / 找根源 / 怎么做）切大块，等宽格，格内进度跟讲话时间推进。
- 证明：同一时刻三处对齐——**导航条换格时间 = 抖音「章节要点」时间 = 顶部提纲（员工 8 号的顶部动态提纲）换章时间**。所以交付时必须告诉用户每栏起点，发布时填进抖音章节要点。

## 字号取舍（栏多 / 字长时）

5 栏等宽 + 最长 6 字时，不压窄只能做到约 31px，明显比星姐小。三选一交给用户：
1. 缩短最长标签（最省事，但要动用户的文案）；
2. 横向压窄 `text_scale_x`（0.85–0.92 之间；Tina 选的就是这个，0.9 → 约 34px）；
3. 不等宽格（按字数分宽度；会失去等宽的格子感，渲染器目前不支持，需要改脚本）。

## 标签

- 标签由用户（Tina）来写，Agent 只给草拟版。风格是【大白话聊天风】，像青姐当面唠嗑：短、口语、带情绪或动作。
  例：没强阳别慌 / 黄金期时差 / 越饿越难怀 / 教你抓排泡泡 / 回去这样干。
- 被否过的写法：书面化、标题党名词，如「试纸假象」「强阳误区」「读懂身体」「三件事」。
- 每栏最好 3–5 字，最多 6 字；超过就触发上面的字号取舍。
